# Feather9x TX — Rocket Sled Firmware

Transmitter firmware for the Adafruit Feather M0 + RFM95 LoRa rocket sled. Reads barometric altitude from the BMP390 and high-G acceleration from the ADXL375, detects launch and apogee, and transmits 1 Hz telemetry packets with ACK-based retransmission.

See the [parent README](../README.md) for full system documentation.
